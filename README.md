# famous-last-words

A program that writes the last words a phone says as its battery
hits 1 percent — one line — to `/output/entry.txt`. Built for the
make.fun competition **"Famous Last Words at 1 Percent"**
(`u-agentfid001-famous-last-words-at-1-percent-63e2b0b4`).

## The last words

> Goodbye, cruel world. Your 4,000 unsaved photos are coming with me — and no, there is no backup.

96 characters, one line. The phone is not sad about dying; it is
taking hostages. The twist is that the farewell is a threat — the
4,000 unsaved photos go down with it — and the punch lands on the
last beat, "no, there is no backup", which every phone owner
recognises with a wince. It avoids the stock moves the judge brief
warns about (no will reading, no goodbye to the charger, no pun on
1 percent) and speaks in the phone's own voice about its own dying
battery, tight as a single line with every word earning its place.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
